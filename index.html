Sobre mim

Olá! Sou o Lucas Fernando, entusiasta do desenvolvimento de software e estudante de Engenharia de Software no Eniac. Atualmente, concilio minha rotina profissional na Academia Gaviões com uma dedicação intensa ao estudo de tecnologias Back-End. Meu foco principal hoje é o ecossistema Java, onde me especializo no framework Spring Boot para a criação de Web Services e APIs RESTful eficientes e escaláveis. Acredito que o desenvolvimento de um back-end sólido é a base para qualquer solução tecnológica de sucesso, e busco constantemente aplicar boas práticas de programação e arquitetura de dados em meus projetos. Estou em busca de oportunidades onde eu possa aplicar meu conhecimento técnico em projetos reais, colaborando com equipes que valorizem a inovação e o código de qualidade.
